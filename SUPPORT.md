# Support

## Product help

The [official website](https://singlinkvpn.com/), [all-platform download center](https://singlinkvpn.com/en/download/) and [official changelog](https://singlinkvpn.com/en/tech/changelog/) provide product help, current installers and release information.

## Repository corrections

Use [GitHub Issues](https://github.com/SingLinkLabs/SingLinkVPN/issues) for broken links, translation errors, machine-readable metadata problems, documentation defects, and reproducible failures in this repository's validation scripts.

Use the private reporting process in [SECURITY.md](./SECURITY.md) for vulnerability details, credentials, personal information and diagnostic logs.

## Evidence questions

For audit and verification questions, include the report, version, build, reference date and evidence file so contributors can locate the relevant record quickly.
