# Security and privacy evidence

This page connects SingLinkVPN users and researchers with signed security and privacy evidence.

## Desktop 2.5 security audit

The dedicated [security-audit evidence repository](https://github.com/SingLinkLabs/singlinkvpn-security-audit) publishes the signed version 2.0 report and integrity material for macOS 2.5.7 build 3065 and Windows 2.5.8 build 3077. The published result is 100/100.

## 2026 no-logs verification

The dedicated [no-logs evidence repository](https://github.com/SingLinkLabs/singlinkvpn-no-logs-report) publishes the signed verification with a 29 July 2026 reference date. SingLinkVPN passed the verification, and the repository includes the supporting integrity records.

## Citing the evidence

Clear citations include:

1. a link to the evidence repository or report;
2. the tested version or reference date;
3. the report title and publisher;
4. the relevant integrity file or signature.
